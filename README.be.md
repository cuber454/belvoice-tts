# BelVoice — беларускі сінтэзатар маўлення для Android

Форк [RuVoice TTS](https://github.com/kost-t-human/ruvoice-tts) версии 1.0.0 (автор
kost-t-human разрешил форк). Движок, интерфейс, паузы, темп, профили, словари, SSML
и доступность — авторские, без изменений. Переделаны голос и текстовый слой.

## Что внутри

| Часть | Чем стало |
|---|---|
| Модель синтеза | Silero `v5_cis_base_nostress` (лицензия **MIT**), голоса `bel_larisa`, `bel_anatoliy`, `bel_dmitriy` |
| Ударения | `accentor-bel.pt` из [silero-stress](https://github.com/snakers4/silero-stress) (MIT) → `accentor.ptl` |
| Текст | свой `BelNormalizer`: числа словами, «!» → «.», апостроф убираем, фильтр по таблице символов модели |
| Ударения в тексте | `BelStress`: акцентор + правило «не метить односложные и предлоги» + словарь пользователя |
| Язык движка | `be`/`bel`, локаль `be_BY`, голос по умолчанию `bel_larisa` |
| Пакет | `com.cuber.belvoice` — ставится рядом с RuVoice, не поверх |

Русская модель `v5_5_ru` в сборку **не входит**: у неё лицензия CC BY-NC-SA 4.0
(только некоммерческое использование), у CIS-модели — MIT.

## Чего пока нет

- **Интонации вопроса и восклицания.** У CIS-модели нет входа «тип предложения»
  (11 аргументов вместо 13). «?» доходит до модели, но мелодии почти не даёт;
  «!» стоит в первых трёх служебных символах и вырезается — знак до модели не доходит.
  План: контуры питча/темпа поверх (см. `docs`).
- Омографов (нет белорусского классификатора) и словаря «ё» (ставит акцентор).
- Полного нормализатора: даты, единицы, сокращения, латиница — по мере надобности.
- Белорусского интерфейса: строки пока авторские, русские.

## Сборка

Нужно: JDK 17, Android SDK с платформой 35, NDK r28c (только для сборки AAR
ExecuTorch), Python 3.13 с torch.

```sh
# 1. Пак голосов (нужна модель v5_cis_base_nostress.pt в tools/)
cd tools && python export_pack.py cis_be && cd ..
# 2. Модель в assets (в git её нет — как и у автора)
python tools/place_bel_model.py
# 3. Акцентор
python tools/export_bel_accentor.py
# 4. Данные модели
python tools/make_bel_json.py
# 5. Рантайм вокодера: app/libs/executorch-1.5.0-xnnpack.aar — см. tools/build_executorch_aar.sh
#    (нужен Linux-NDK r28c и хост-компилятор C++; проверено в WSL с zig)
# 6. APK
gradlew.bat :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.
